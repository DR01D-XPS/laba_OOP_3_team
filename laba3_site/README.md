# Локальный магазин «Драгоценная Лилия»

Django 5.2, SQLite, серверные Django-шаблоны. Используется Bisum из репозитория: `assets/css/vendor.css`, `assets/css/style.css`, Bootstrap-сетка, карточки, кнопки и исходные скрипты. Данные и формы подставляются сервером в `main/templates/shop/`. Используются только исходные CSS и скрипты Bisum, отдельного фронтенд-приложения нет.

## Запуск в этой рабочей папке

Дважды нажмите `start_local.bat` в этой папке, затем откройте http://127.0.0.1:8000/.

Окно сервера должно оставаться открытым. Для остановки нажмите Ctrl+C.

## Установка на другом компьютере

Нужен Python 3.11 или новее. Из папки с `manage.py`:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py import_catalog
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000
```

## Исходные данные

- `source_data/каталог.xlsx` — оригинал, 190 строк с вариантами украшений.
- `source_data/картинки.rar` — оригинальный архив.
- `source_data/images/` — распакованные исходные изображения.
- `media/products/` — оптимизированные копии для сайта. Одно фото может использоваться у нескольких размеров.
- `db.sqlite3` — локальные товары, пользователи, заказы и сессии.

Импорт обновляет товары по `idВариант`, повторный запуск не создаёт дубликаты. **Повторный импорт восстанавливает цены и остатки из Excel**, в том числе уменьшенные после заказов. Для рабочего магазина нужен отдельный процесс синхронизации.

Каталог сохраняет все исходные поля. Строки с одинаковым артикулом и разными размерами остаются отдельными позициями.

## Функции

Категории, поиск без учёта регистра (включая кириллицу), фильтры по бренду/цене/наличию, сортировка, страницы каталога, карточки с вариантами, избранное, корзина, гостевой заказ, регистрация/вход/выход, история заказов. Цена считается на сервере; остатки списываются в транзакции. Доступ к заказу ограничен сессией гостя или его аккаунтом.

Заказы сохраняются локально. Сайт не отправляет данные настоящему магазину, не принимает онлайн-платежи и не отправляет email. Выбран самовывоз и оплата при получении.

## Администрирование и проверки

```powershell
python manage.py createsuperuser
python manage.py check
```

Адрес панели — `/admin/`. Создайте собственный аккаунт администратора командой выше: готовых паролей в проекте нет. Панель позволяет редактировать товары и менять статусы заказов. Возврат остатка после отмены пока выполняется администратором вручную.

Настройки предназначены для localhost (`DEBUG=True`); перед публикацией нужна отдельная конфигурация.
